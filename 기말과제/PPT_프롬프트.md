## 슬라이드 5 — 핵심 기능 ② AI 분석 3종 세트

**프롬프트:**
```
PPT 슬라이드 "AI 기술 분석 3종 세트" 내용을 작성해줘.

3가지 AI 기능을 카드 형식으로:

[카드 1] 지지·저항 레벨 (S/R)
- 알고리즘: K-means 클러스터링
- 과거 고점/저점 데이터를 군집화해 지지·저항 가격대 자동 탐지
- 차트에 수평선 오버레이로 표시

[카드 2] 추세선 자동 생성
- 알고리즘: scipy argrelextrema + 선형 회귀
- 고점·저점 연결 추세선 (R²≥0.5 필터로 신뢰도 보장)
- 상승/하락/횡보 추세 자동 구분

[카드 3] 이상 감지 (Anomaly Detection)
- 알고리즘: PyTorch Autoencoder
- 재구성 오차(reconstruction error)로 비정상 가격 움직임 탐지
- 주황색 하이라이트로 이상 구간 시각화

하단에 "토글 버튼 ON/OFF로 원하는 분석만 선택 표시" 문구 추가.
```

**스크린샷 위치:** S/R + 추세선 오버레이 활성화된 차트 화면

## 슬라이드 제작 순서 가이드

1. 위 프롬프트를 순서대로 Claude에 입력 → 텍스트 내용 생성
2. Google Slides 또는 PowerPoint에서 슬라이드 생성
3. 다크 테마 적용 (배경: #0f172a 또는 #1e293b, 텍스트: 흰색)
4. 앱을 실행하고 각 슬라이드 지정 화면 캡처 (Cmd+Shift+4)
5. 스크린샷을 지정 위치에 삽입, 모서리 둥글게 + 그림자 효과
6. 폰트: 제목 Bold 36pt / 본문 18pt / 캡션 14pt
